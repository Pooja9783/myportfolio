# Pooja Sankhala | Full Stack & AI Engineer Portfolio

A modern and responsive developer portfolio built to showcase my experience, projects, technical skills, certifications, and journey into Full Stack AI Engineering.

## ✨ Features

* Responsive portfolio design
* Professional experience showcase
* Technical skills section
* Featured projects
* Certifications with certificate previews
* Interactive AI portfolio assistant
* Modern dark UI with orange accents

## 🛠️ Tech Stack

* React
* TypeScript
* Vite
* Tailwind CSS
* Lucide React
* Google Gemini AI

## 🏗️ Architecture

The portfolio is built using reusable React components and TypeScript, with portfolio content managed through centralized data structures.

The application follows a component-based architecture to keep the codebase modular, maintainable, and easy to extend.

The AI portfolio assistant is designed as a separate service layer and can be integrated with a Node.js and Express backend for secure API communication and AI integrations.

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/Pooja9783/YOUR_REPOSITORY_NAME.git
```

### Navigate to the project

```bash
cd YOUR_REPOSITORY_NAME
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

## 📦 Build for Production

```bash
npm run build
```
